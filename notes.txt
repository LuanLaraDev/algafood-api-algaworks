Para podermos usar o Flyway adicionamos as dependências no pom.xml:

		<dependency>
			<groupId>org.flywaydb</groupId>
			<artifactId>flyway-core</artifactId>
		</dependency>

		<dependency>
			<groupId>org.flywaydb</groupId>
			<artifactId>flyway-mysql</artifactId>
		</dependency>

Sendo a segunda específica para usarmos com MySQL.

Desativamos a criação automática do schema no application.properties (se estiver ativa).

Para o funcionamento do Flyway adicionamos os arquivos sql na pasta db/migration dentro de resources.
Os arquivos devem ter o seguinte padrão:

V1__descrição-da-migration.sql
V001__descrição-da-migration.sql
V1.0__descrição-da-migration.sql
V20250202175040__descrição-da-migration.sql

Vale resaltar que normalmente não popularemos nossas tabelas pelo migration, pois a não ser que sejam dados que vão
estar presentes em produção, não devemos adiciona-los via migration.
