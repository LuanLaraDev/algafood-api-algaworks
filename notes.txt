Para melhorar nosso código, podemos criar uma fábrica de Specifications, com essa fábrica é possível obter instâncias
das nossas Specifications sem ser necessário crian instâncias manualmente. Para melhorar mais nosso código podemos
utilizar de classes anônimas, onde nossa fábrica gera instâncias de Specification sem necessitar de um classe específica
pois a interface specification é uma interface funcional e portanto podemos criar uma instância de forma anônima.

Podemos ver como isso é feito na classe RestauranteSpecs.
